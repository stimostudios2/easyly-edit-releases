# Easyly Edit — aggiornamenti

Qui ci sono solo gli installer e gli aggiornamenti di Easyly Edit per macOS e Windows (beta).
Il codice sorgente non è pubblicato.

Ogni versione è nelle **Releases**. L'app controlla da sola se ce n'è una nuova e scarica solo i file cambiati; ogni aggiornamento è firmato e l'app installa solo aggiornamenti con una firma valida.
